# Momepy

[Momepy](https://docs.momepy.org) - Urban Morphology Measuring Toolkit QGIS 
plugin.

It is currently in a pre-alpha version.

## Requirements

momepy plugin requires [momepy](https://docs.momepy.org) >= 0.10.0.

### Setup

To install dependencies use [pixi](https://pixi.sh)

```
pixi install
pixi run qgis
```

## Plugin installation

Clone repository, compress the plugin directory using zip. Install the .zip
file in QGIS.
